# 차량용 블랙박스 인텔리전스 Q&A 시스템 (Hybrid RAG)

차량용 블랙박스 및 전장 부품 데이터시트(비정형)와 BOM/단가표(정형)를 통합 분석하여, FAE(Field Application Engineer) 수준의 전문적인 답변을 제공하는 **하이브리드 RAG 에이전트 시스템**입니다.

## 📌 1. 프로젝트 개요 및 배경
* **도입 배경:** 수많은 부품 라인업을 보유한 ODM 환경에서, 기존 FAE가 방대한 데이터시트(PDF)와 BOM을 수작업으로 대조하며 답변하던 병목 현상과 휴먼 에러 발생.
* **핵심 목표:** 환각 현상을 원천 차단하고, 100% 데이터시트 기반의 부품 스펙 비교 및 단가 계산 자동화 파이프라인 구축.

## ⚙️ 2. 하이브리드 아키텍처 및 파이프라인
본 프로젝트는 데이터의 무결성과 검색의 깊이를 모두 확보하기 위해 투트랙 파이프라인과 오토노머스 에이전트를 도입했습니다.

1. **정형 데이터 파이프라인 (SQL)**
   * `SQLite` 인메모리 조인 캐싱을 통해 팩트 기반 단가 연산 및 필터링 수행. (수학적/논리적 결함 0% 달성)
2. **비정형 데이터 파이프라인 (Vector DB)**
   * `PyMuPDF` 기반 문서 파싱 및 `ChromaDB` 채택 (메타데이터 통합 관리 및 로컬 영구 저장 최적화).
3. **LLM 에이전트 제어 (Function Calling)**
   * `GPT-4o-mini`가 3가지 핵심 도구(정형 필터링, 단가 집계, 시맨틱 검색)를 사용자 질의에 맞춰 자율적으로 판단하고 호출.

## 🧪 3. 핵심 엔지니어링 성과 (Engineering Highlights)

### 🎯 [Highlight 1] 검색 품질 최적화를 위한 2-Step Grid Search
RAG 시스템의 성능을 극대화하기 위해, 무작정 최신 모델을 도입하지 않고 자사 데이터셋에 맞는 임베딩 모델과 Chunk Size 조합을 교차 검증했습니다.

| 모델 | Chunk Size 특성 | 주요 성능 결과 및 한계 |
| :--- | :--- | :--- |
| **Qwen3 (0.6B)** | 클수록 유리 (800) | 안정적인 팩트 전달과 구조화에 능하나, 깊은 문서 검색에서 한계 노출. |
| **BGE-M3** | 작을수록 유리 (500) | 촘촘한 검색력으로 미세 스펙까지 발굴. 자체 부품 카운팅 등 혁신적 분석력 증명. (단, Chunk 800에선 심각한 환각 발생) |

**✅ 최종 아키텍처 의사결정: `BGE-M3 (Chunk 500 / Overlap 100)` 채택**
* **채택 근거:** 실무 엔지니어링 환경에서는 단순 조회를 넘어선 기술 분석이 필수적입니다. BGE 모델은 단순 나열을 넘어 **부품 수를 자체 통계화**하고, 검색 스펙을 바탕으로 **ADAS 등 산업 응용 분야까지 확장된 통찰**을 제공하여 최종 도입을 결정했습니다.

### 🛡️ [Highlight 2] LLM 환각 원천 차단 로직
전장 부품 분야의 치명적인 데이터 오류를 막기 위해 다음의 제어 로직을 구현했습니다.
* **SQL 팩트 강제 결합:** 제조사 및 단가는 VectorDB가 아닌 SQL 테이블에서만 가져오도록 도구(Tool) 분리.
* **프롬프트 통제:** 데이터가 없을 경우 억측하지 않고 *"DB에 정보가 없습니다"*로만 응답하도록 시니어 FAE 페르소나 시스템 프롬프트 구축.

# 차량용 블랙박스 인텔리전스 Q&A 시스템 (Hybrid RAG)

차량용 블랙박스 및 전장 부품 데이터시트(비정형)와 BOM/단가표(정형)를 통합 분석하여, FAE(Field Application Engineer) 수준의 전문적인 답변을 제공하는 **하이브리드 RAG 에이전트 시스템**입니다.

##  1. 프로젝트 개요 및 배경
* **도입 배경:** 일반적인 사전학습 모델은 학습 데이터의 컷오프 시점 문제로 인해 최신 부품 사양을 반영하지 못하거나, 기업 내부의 기밀 규격서에 접근할 수 없다는 한계가 존재하고, 사실과 다른 정보를 생성하는 환각 현상은 정확한 수치와 규격이 필수적인 전장 부품 분야에서 치명적인 오류를 야기할 수 있음.
* **핵심 목표:** 환각 현상을 원천 차단하고, 100% 데이터시트 기반의 부품 스펙 비교 및 단가 계산 자동화 파이프라인 구축.

##  2. 하이브리드 아키텍처 및 파이프라인
본 프로젝트는 데이터의 무결성과 검색의 깊이를 모두 확보하기 위해 데이터베이스를 이원화하여 관리하는 하이브리드 구조와 LLM 에이전트를 도입했습니다.

1. **정형 데이터 파이프라인 (SQL)**
   * `SQLite` 인메모리 조인 캐싱을 통해 팩트 기반 단가 연산 및 필터링 수행. (수학적/논리적 결함 0% 달성)
2. **비정형 데이터 파이프라인 (Vector DB)**
   * `PyMuPDF` 기반 문서 파싱 및 `ChromaDB` 채택.
   * **`FAISS` 대신 `ChromaDB` 채택 근거**: 단순 밀리초 단위의 대규모 연산 속도보다는, 출처나 페이지 등 문서의 메타데이터 통합 관리와 안정적인 로컬 영구 저장(Persistent) 환경이 RAG 신뢰도에 더 적합하다고 판단했습니다.
3. **LLM 에이전트 제어 (Function Calling)**
   * `GPT-4o-mini`를 시스템의 두뇌로 도입했습니다. 사용자의 복합적인 질의를 분석해 3가지 핵심 도구(정형 필터링, 단가 집계, 시맨틱 검색) 중 필요한 것을 에이전트가 자율적으로 판단하고 순차 호출하는 강력한 Function Calling을 구현했습니다.

##  3. 핵심 엔지니어링 성과 (Engineering Highlights)

###  검색 품질 최적화를 위한 2-Step Grid Search 및 4대 평가지표
RAG 시스템의 성능을 극대화하기 위해, 자체 구축한 **4대 핵심 평가 지표**(정보 정확성, 답변 완전성, 추론 및 인사이트, 형식 준수)를 기준으로 고객사 데이터셋에 맞는 임베딩 모델과 Chunk Size 조합을 교차 검증했습니다.

### 🛡️ LLM 환각 원천 차단 로직
전장 부품 분야의 치명적인 데이터 오류를 막기 위해 다음의 제어 로직을 구현했습니다.
* **SQL 팩트 강제 결합:** 제조사 및 단가는 환각 우려가 있는 Vector DB가 SQL 테이블에서만 가져오도록 도구(Tool)를 철저히 분리했습니다.
  * tool_filter_models_advanced: 브랜드 및 부품 제조사 기반의 SQL 필터링 검색
  * tool_get_component_avg_price: 특정 카테고리/제조사 부품의 평균 단가 산출 및 통계 분석
  * tool_search_vdb: Chroma DB를 통한 상세 기술 문서 시맨틱 검색
* **프롬프트 튜닝 (Persona Engineering):** 에이전트에게 시니어 FAE 페르소나를 부여하여, 검색된 데이터가 없을 경우 억측하지 않고 "현재 DB 내에 관련 정보가 확인되지 않습니다"라고 단호히 응답하도록 통제력을 극대화했습니다.

### 💻 Local 환경에서 실행하기 (For Developers)
로컬 환경에서 직접 코드를 돌려보고 싶으신 경우 아래 절차를 따릅니다.

**1. 저장소 클론 및 패키지 설치**
Python 3.10 이상의 가상 환경(Virtual Environment) 세팅 후 아래 명령어를 실행하여 필수 패키지를 설치합니다.
```bash
git clone [https://github.com/moobong046/super_teamproject3.git](https://github.com/moobong046/super_teamproject3.git)
cd super_teamproject3
pip install -r requirements.txt
```
**2. 환경 변수 등록**
프로젝트 루트 디렉토리에 .env 파일을 생성하고 OpenAI API 키를 입력합니다.
```text
OPENAI_API_KEY=your_api_key_here
```
**3. Gradio 앱 실행**
```text
# 허깅페이스 호환성을 고려한 Gradio 메인 스크립트 실행
python api/main_rag.py 
```
